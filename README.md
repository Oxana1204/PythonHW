# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --alluredir=./allure-results
   ```

   Эта команда запустит все тесты и сохранит результаты в директорию `./allure-results`.

---

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите тестирование трех форм:
    2.1. Проверка функциональности калькулятора
   - **Название теста**: `Тестирование калькулятора: 7 + 8 = 15`.
   - **Описание теста**: тест проверяет корректность работы калькулятора.
   - **Шаги теста**:
     - Открытие страницы калькулятора.
     - Установка задержки.
     - Нажатие кнопок.
     - Ожидание результата.
     - Проверка результата.
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.
    2.2 Проверка функциональности формы с данными
   - **Название теста**: `Тестирование формы с персональными данными`.
   - **Описание теста**: тест проверяет корректность заполнения формы с данными.
   - **Шаги теста**:
     - Открытие страницы целевой формы.
     - Заполнение формы персональными данными:
        имя;
        фамилия;
        адрес;
        email;
        телефон;
        zip code (не заполняется для проверки);
        город;
        страна;
        профессия;
        компания.
     - Нажатие кнопоки для отправки формы.
     - Ожидание результата.
     - Проверка результата.
   - **Результат**: Не заполненное поле zip code подсвечено красным, остальные поля подсвечены зеленым.
     2.3. Проверка функциональности интернет-магазина
   - **Название теста**: `Тестирование интернет-магазина`.
   - **Описание теста**: тест проверяет корректность работы интернет-магазина.
   - **Шаги теста**:
     - Открытие страницы интернет-магазина.
     - Авторизация как пользователь standard_user.
     - Добавление в корзину трех товаров.
     - Переход в корзину.
     - Нажатие кнопки Checkout.
     - Заполнение формы своими данными.
     - Нажатие кнопки Continue.
     - Прочитать со страницы итоговую стоимость.
     - Закрыть браузер.
   - **Результат**: Успешное выполнение заказа, проверка итоговой суммы заказа, равной $58.29 или ошибка.
